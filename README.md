# Student CGPA Calculator 🎓

A simple, user-friendly *C++ Console Application* designed to calculate a student's Semester Grade Point Average (GPA) / Cumulative Grade Point Average (CGPA) based on course grades and credit hours.

This project was developed as *Task 1* during my *C++ Programming Internship at CodeAlpha*.

---

## 📌 Features
- *Dynamic Input:* Calculates CGPA for any number of courses entered by the user.
- *Input Validation:* Restricts invalid grade entries and prompts the user until a valid grade (A, B, C, D, F) is entered.
- *Case Insensitive:* Accepts both uppercase and lowercase grade inputs (e.g., a or A).
- *Structured Report Display:* Presents a formatted semester summary showing course-wise grades, credit hours, total credit hours, and final CGPA formatted to 2 decimal places.

---

## 🛠️ Tech Stack & Concepts Used
- *Language:* C++
- *Header Files:* <iostream>, <iomanip>
- *Core Concepts:* Arrays, switch-case statements, for loops, functions, and standard input/output formatting.
